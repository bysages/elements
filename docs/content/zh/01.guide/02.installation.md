## 安装

:::code-group
```bash [Vue]
pnpm add @bysages/vue @bysages/core
```
```bash [React]
pnpm add @bysages/react @bysages/core
```
```bash [Solid]
pnpm add @bysages/solid @bysages/core
```
```bash [Svelte]
pnpm add @bysages/svelte @bysages/core
```
:::

各包装层会自行引入 `@bysages/core`；只有主题引擎需要你直接安装。

## 应用主题

在客户端调用一次 `applyTheme`——它把主题属性写到根元素上并持久保存。

```ts
import { applyTheme, initTheme } from "@bysages/core";

// 恢复已保存的主题，并在 mode 为 "system" 时跟随操作系统
initTheme();

// 或者显式设置一套完整主题
applyTheme({ mode: "dark", accent: "celadon", scene: "studio" });
```

## 使用组件

```vue
<script setup lang="ts">
import { Button } from "@bysages/vue";
</script>

<template>
  <Button variant="solid" tone="ink">发布</Button>
</template>
```

每个包装层在首次使用时注入自己的样式表（含令牌层）——无需记住任何 CSS 引入。若在服务端渲染，把 `@bysages/core` 的 `tokensCss` 传给 head 标签，首屏绘制便已带着主题。
