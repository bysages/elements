---
title: 主题
description: 五个主题维度、取值与默认值，以及令牌覆盖方式。
---

Elements 的视觉系统由根元素上的五个属性决定。`@bysages/core` 的主题引擎负责写入这些属性并保存变更；静态页面也可以直接手写它们。

| 属性 | 取值 | 默认值 | 控制内容 |
| --- | --- | --- | --- |
| `data-theme` | `light`、`dark`、`system` | `system` | 宣纸和漆黑两种明暗模式 |
| `data-accent` | `auto`、`ink` 与矿物颜料 | `auto` | 主要操作和焦点光晕 |
| `data-scene` | `auto` 与已注册场景 | `auto` | 形状、间距、动效和光线 |
| `data-density` | `compact`、`default`、`comfortable`、`spacious` | `default` | 留白和控件间距 |
| `data-contrast` | `auto`、`normal`、`high` | `auto` | 文字、细线和焦点强度 |

```ts
import { applyTheme } from "@bysages/core";

applyTheme({
  mode: "dark",        // "light" | "dark" | "system"
  accent: "zhusha",    // "auto" | "ink" | "qinghua" | "celadon" | "zhusha" | "feicui" | "jilan" | "qingjin"
  scene: "civic",      // "auto" | "civic" | "enterprise" | "studio" | "tech" | "cupertino" | "expressive" | "fluent" | "material" | "sketch" | "missive" | "dispatch" | "metric" | "new-york" | "archive"
  density: "spacious", // "compact" | "default" | "comfortable" | "spacious"
  contrast: "high",    // "auto" | "normal" | "high"
});
```

`applyTheme` 会把省略的维度和当前主题合并，写入根元素属性，并返回解析后的 `Theme`。逻辑主题保存在 `localStorage` 的 `bs-theme` 键里；传 `persist: false` 可以只修改当前页面而不保存。`initTheme` 负责恢复已保存的主题，并在 `mode` 为 `system` 时跟随操作系统；`getTheme` 读取当前逻辑主题。

## 明暗

`light` 是宣纸模式。`dark` 是暖调漆黑——不是纯 `#000`——同样的色相关系会提到更亮的层级。`system` 在应用主题时通过 `prefers-color-scheme` 解析。

## 主题色

`data-accent` 决定主要操作块和焦点光晕的颜色。成功、警告、危险和信息保持语义色，不随主题色变化。

| 取值 | 颜色 | 说明 |
| --- | --- | --- |
| `ink` | 单色墨 | 显式关闭主题色颜料 |
| `qinghua` | 钴蓝 | 青花 |
| `celadon` | 水绿 | 天水碧 |
| `zhusha` | 朱砂红 | 印泥红；典章的默认搭配 |
| `feicui` | 翡翠绿 | 翡翠；家书的默认搭配 |
| `jilan` | 霁蓝 | 霁蓝；公牍的默认搭配 |
| `qingjin` | 青金石蓝 | 青金；格律的默认搭配 |
| `auto` | 场景搭配 | 随当前场景解析 |

## 场景

`data-scene` 调整整站的形状、密度、动效和光线方向，不分叉组件。

| 取值 | 名称 | 面向 | 默认主题色 | 默认对比度 |
| --- | --- | --- | --- | --- |
| `civic` | 典章 | 政务和大龄用户桌面 | `zhusha` | `high` |
| `enterprise` | 信笺 | 安静的商用长时界面 | `qinghua` | `normal` |
| `studio` | 雅集 | 设计和编辑类产品 | `celadon` | `normal` |
| `tech` | 司南 | 现代工具类产品 | `ink` | `normal` |
| `cupertino` | 圆融 | 柔和轻盈的手持界面 | `qinghua` | `normal` |
| `expressive` | 飞白 | 活泼、动效优先的产品 | `zhusha` | `normal` |
| `fluent` | 流水 | 克制的生产力套件 | `qinghua` | `normal` |
| `material` | 格物 | 靠投影分层的界面 | `celadon` | `normal` |
| `sketch` | 写意 | 手绘趣味产品 | `zhusha` | `normal` |
| `missive` | 家书 | 熟悉的手持端产品 | `feicui` | `normal` |
| `dispatch` | 公牍 | 办公场景的手持端产品 | `jilan` | `normal` |
| `metric` | 格律 | 讲究章法的生产力套件 | `qingjin` | `normal` |
| `new-york` | 玄素 | 单色开发者工具 | `ink` | `normal` |
| `archive` | 档案 | 档案工作室和编辑排版栅格 | `ink` | `normal` |

典章、信笺、雅集和司南是 Elements 自己的受众场景；其余场景按共同气质命名，不直接使用产品品牌名：

| 取值 | 参考气质 |
| --- | --- |
| `cupertino` 圆融 | iOS 设计语言 |
| `expressive` 飞白 | 弹簧动效驱动的移动端设计 |
| `fluent` 流水 | Fluent 克制的生产力套件 |
| `material` 格物 | Material 靠投影分层的立体风格 |
| `missive` 家书 | WeUI 等开源移动端样式规范 |
| `dispatch` 公牍 | WeUI for Work |
| `metric` 格律 | TDesign 的企业级章法 |
| `sketch` 写意 | 手绘速写本与漫画 |
| `new-york` 玄素 | shadcn/ui 的单色开发者气质 |
| `archive` 档案 | 瑞士国际主义排版与影像工作室档案 |

场景默认搭配只在对应维度为 `auto` 时生效；显式设置的 `accent` 或 `contrast` 始终优先。例如 `applyTheme({ scene: "civic", accent: "qinghua" })` 保留典章的形状，但使用钴蓝。`SCENE_DEFAULT_ACCENT` 和 `SCENE_DEFAULT_CONTRAST` 导出默认搭配表。

## 密度和对比度

`data-density` 只调整留白、间距和控件间隙，不改字号。`compact` 收紧布局，`default` 保持平衡，`comfortable` 增加呼吸感，`spacious` 拉开最大间距。

`data-contrast="high"` 会把次级文字和细线提到接近主级的强度，并加深焦点光晕。`normal` 是基准；`auto` 跟随场景。

## 覆盖令牌

主题负责选择令牌值，应用代码可以用 CSS 替换它们。令牌位于 `@layer bs.tokens`，不加 layer 的规则无需提高优先级就能覆盖：

```css
:root {
  --bs-radius-sm: 4px;
  --bs-color-primary: var(--bs-color-ink);
}
```

主题属性会级联，因此也可以只挂在某个子树上。`data-scene="studio"` 的面板可以嵌在 civic 页面里，而页面其他部分保持原场景。
