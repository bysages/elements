Elements 是 By Sages 的界面组件库：无头状态机负责交互，纸墨设计语言负责视觉。

## 分层

| 层   | 技术            | 职责             |
| ---- | --------------- | ---------------- |
| 组件 | 无头状态机      | 交互、状态、ARIA |
| 样式 | `@bysages/core` | 唯一的视觉层     |
| 主题 | 设计令牌        | 色板、明暗、密度 |
