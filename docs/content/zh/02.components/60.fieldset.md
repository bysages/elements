## 属性

### Fieldset

The one-tag path: one label and optional description around the
caller's controls; compound or bespoke groups keep the anatomy.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `label` | `String` | `undefined` | — |
| `description` | `String` | `undefined` | — |
| `disabled` | `Boolean` | `false` | — |
| `invalid` | `Boolean` | `false` | — |
| `required` | `Boolean` | `false` | — |

### Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `disabled` | `boolean \| 'true' \| 'false'` |  | 是否禁用字段集 |
| `id` | `string` |  | 字段集的 id |
| `invalid` | `boolean` |  | 字段集是否无效 |

### ErrorText

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### HelperText

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### Legend

纯造型的部件——自身没有属性，沿用部件结构的共享样式。
