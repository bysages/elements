## 属性

### Toggle

The complete pressed seal behind one label: the default content
swaps through the indicator, so one child serves both states.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `label` | `String` | `undefined` | The accessible name when the content is only a glyph. |

### Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `defaultPressed` | `boolean` |  | toggle 的默认按压状态 |
| `disabled` | `boolean` |  | toggle 是否禁用 |
| `pressed` | `boolean` |  | toggle 的按压状态 |

### Indicator

纯造型的部件——自身没有属性，沿用部件结构的共享样式。
