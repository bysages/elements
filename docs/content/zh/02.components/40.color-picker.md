## 属性

### ColorPicker

颜色选择器的完整外观：色块触发器展开取色区域、吸管、色相和透明度滑块、rgba/hsla 通道输入与格式切换；传入 `swatches` 时显示保存色样行。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `modelValue` | `[String, Object] as PropType<string \| Color>` | `undefined` | 取色器的 v-model 值 |
| `defaultValue` | `[String, Object] as PropType<string \| Color>` | `undefined` | 初始颜色值；无需控制取色器颜色值时使用 |
| `disabled` | `Boolean` | `false` | 取色器是否禁用 |
| `invalid` | `Boolean` | `false` | 取色器是否无效 |
| `required` | `Boolean` | `false` | 取色器是否必填 |
| `label` | `String` | `undefined` | 取色器标签文本 |
| `swatches` | `Array as PropType<string[]>` | `() => []` | 保存色样行的颜色值列表 |
| `defaultFormat` | `String as PropType<ColorPickerColorFormat>` | `"rgba"` | 初始通道格式，可为 `rgba` 或 `hsla` |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | 色样按钮的高度，可为 `sm`、`md` 或 `lg` |
