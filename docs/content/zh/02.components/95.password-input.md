## 属性

### PasswordInput

The one-tag path: the masked field and reveal control. Visibility
state, password-manager rules, and validation stay on the anatomy.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `modelValue` | `String` | `undefined` | — |
| `defaultValue` | `String` | `undefined` | — |
| `label` | `String` | `undefined` | — |
| `placeholder` | `String` | `undefined` | — |
| `autoComplete` | `String as PropType<"current-password" \| "new-password">` | `undefined` | — |
| `disabled` | `Boolean` | `false` | — |
| `invalid` | `Boolean` | `false` | — |
| `required` | `Boolean` | `false` | — |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | — |

### Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `autoComplete` | `passwordInput.Props['autoComplete']` |  | 输入框的 autocomplete 属性 |
| `defaultVisible` | `boolean` |  | 密码是否默认可见 |
| `disabled` | `boolean` |  | 是否禁用输入框 |
| `id` | `string` |  | 组件内部状态机的唯一标识 |
| `ids` | `passwordInput.Props['ids']` |  | 密码输入框各元素的 id，便于组合使用 |
| `ignorePasswordManagers` | `boolean` |  | 是否忽略密码管理器 |
| `invalid` | `boolean` |  | 输入框是否无效 |
| `name` | `string` |  | 输入框的 name 属性 |
| `readOnly` | `boolean` |  | 输入框是否只读 |
| `required` | `boolean` |  | 输入框是否必填 |
| `translations` | `passwordInput.IntlTranslations` |  | 无障碍元素及其状态使用的本地化文案 |
| `visible` | `boolean` |  | 密码是否可见 |

### Control

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### Indicator

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `fallback` | `string` |  | 密码隐藏时显示的替代内容 |

### Input

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### Label

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### VisibilityTrigger

纯造型的部件——自身没有属性，沿用部件结构的共享样式。
