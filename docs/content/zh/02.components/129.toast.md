## 属性

### Toaster

The common path: a toaster needs no repeated card markup. Machine data
supplies the heading and lead; the default slot still replaces the card.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `toaster` | `Object as PropType<CreateToasterReturn>` |  | — |
