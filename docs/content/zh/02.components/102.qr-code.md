## 属性

### QrCode

The complete printable code behind one payload.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `modelValue` | `String` | `undefined` | — |
| `defaultValue` | `String` | `undefined` | — |

### Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `defaultValue` | `string` |  | 二维码渲染时要编码的初始值；不需要控制二维码值时使用 |
| `encoding` | `qrcode.QrCodeGenerateOptions` |  | 二维码编码选项 |
| `id` | `string` |  | 组件内部状态机的唯一标识 |
| `ids` | `Partial<{ root: string; frame: string; }>` |  | 各元素的 id |
| `modelValue` | `string` |  | 二维码的 `v-model` 值 |
| `pixelSize` | `number` |  | 二维码的像素尺寸 |

### DownloadTrigger

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `fileName` | `string` |  | 文件名 |
| `mimeType` | `DataUrlType` |  | 图像的 MIME 类型 |
| `quality` | `number \| undefined` |  | 图像质量 |

### Frame

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### Overlay

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### Pattern

纯造型的部件——自身没有属性，沿用部件结构的共享样式。
