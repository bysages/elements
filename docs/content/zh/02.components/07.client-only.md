服务端渲染的页面先于浏览器开口：`window` 还读不到，canvas 还没尺寸，
任何押注在它们身上的子树都会撕坏水合契约。`ClientOnly` 把子内容扣留
到客户端挂载之后——服务端先渲染 fallback，随后两者一次换位，服务端
发出的标记与 Vue 期望的标记始终一致。

当一棵子树完全无法在服务端渲染（canvas 图表、地图、编辑器），或它的
首次客户端测量注定与服务端的猜测不一致而闪动时，用它兜住。

## 基础用法

```vue
<script setup>
import { ClientOnly } from "@bysages/vue";
</script>

<template>
  <ClientOnly>
    <template #fallback>
      <p>图表加载中……</p>
    </template>
    <BrowserChart />
  </ClientOnly>
</template>
```

fallback 在服务端渲染、水合完成前一直驻留；挂载后由 default 插槽顶替。
不提供 fallback 时，挂载前该位置保持空白。

## 插槽

| 插槽 | 说明 |
| --- | --- |
| `default` | 子内容，仅在客户端、水合之后渲染 |
| `fallback` | 服务端先行渲染的占位，驻留至挂载为止 |
