## 属性

### Calendar

The date-picker's month grid, standing on the page without its
popup: always open, the trigger gone, the vessel a quiet card. The
title zooms out through month and year grids; the grids themselves
are the date-picker's machinery — value, range selection, and focus
included.

| Prop         | Type                                                        | Default     | Description                                                   |
| ------------ | ----------------------------------------------------------- | ----------- | ------------------------------------------------------------- |
| `modelValue` | `null as unknown as PropType<DatePickerRootProps["value"]>` | `undefined` | Selected date(s) — an array, as the machine speaks in ranges. |
| `min`        | `null as unknown as PropType<DatePickerRootProps["min"]>`   | `undefined` | —                                                             |
| `max`        | `null as unknown as PropType<DatePickerRootProps["max"]>`   | `undefined` | —                                                             |
