## 属性

### MeterLabel

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### MeterValueText

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### MeterTrack

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### MeterRoot

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `value` | `Number` |  | 测量值；限制在 min 和 max 之间 |
| `min` | `Number` | `0` | — |
| `max` | `Number` | `100` | — |
| `level` | `String as PropType<"normal" \| "success" \| "warning" \| "danger">` | `"normal"` | 进度颜色级别；未超过阈值时为 primary，超过后使用对应等级 |
| `label` | `String` | `undefined` | — |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | 轨道厚度档位 |
