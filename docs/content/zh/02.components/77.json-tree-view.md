## 属性

### JsonTreeView

The one-tag path for a read-only tree: `data` and the initial depth
are all a quiet ledger needs; deeper control stays on the anatomy.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `data` | `null` |  | — |
| `defaultExpandedDepth` | `Number` | `1` | — |

### Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `data` | `object` |  | 树中展示的数据 |
| `defaultExpandedDepth` | `number` |  | 默认展开的层级 |
| `quotesOnKeys` | `boolean` |  | 键名是否显示引号 |

### KeyNode

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `node` | `JsonNode` |  | 要渲染的节点 |
| `showQuotes` | `boolean` |  | 键名是否显示引号 |

### Node

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `indentGuide` | `boolean` |  | — |
| `indexPath` | `number[]` |  | — |
| `node` | `JsonNode` |  | — |

### Tree

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

### ValueNode

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `node` | `JsonNodeHastElement` |  | — |
