## 属性

### Indicator

| Prop   | Type            | Default | Description |
| ------ | --------------- | ------- | ----------- |
| `type` | `'on' \| 'off'` |         | —           |

### Root

| Prop            | Type      | Default | Description                            |
| --------------- | --------- | ------- | -------------------------------------- |
| `lazyMount`     | `boolean` |         | Whether to enable lazy mounting.       |
| `swap`          | `boolean` |         | Whether the swap is in the "on" state. |
| `unmountOnExit` | `boolean` |         | Whether to unmount on exit.            |
