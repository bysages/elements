## 属性

### Select

Select：高层选择器。options 生成纸质浮层中的选项；modelValue 支持单个值或多值数组，label 提供字段名，placeholder 提供空态提示。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `modelValue` | `[String, Array] as PropType<SelectFacadeValue>` | `undefined` | 受控的已选值；`multiple` 为 `false` 时是字符串，为 `true` 时是字符串数组 |
| `defaultValue` | `[String, Array] as PropType<SelectFacadeValue>` | `undefined` | 非受控时的初始值；`multiple` 为 `true` 时是字符串数组 |
| `options` | `Array as PropType<NativeSelectOption[]>` |  | 选项集合，每项提供 `label` 和 `value` |
| `multiple` | `Boolean` | `false` | 为 `true` 时允许选择多个选项 |
| `deselectable` | `Boolean` | `false` | 为 `true` 时点击已选项可取消选择；仅单选模式适用 |
| `clearable` | `Boolean` | `true` | Show the clear-value control when the machine allows it. |
| `disabled` | `Boolean` | `false` | 为 `true` 时禁用选择器 |
| `invalid` | `Boolean` | `false` | 为 `true` 时标记选择器无效 |
| `required` | `Boolean` | `false` | 为 `true` 时选择器必填 |
| `readOnly` | `Boolean` | `false` | 为 `true` 时选择器只读 |
| `label` | `String` | `undefined` | 字段标签；未提供时 `placeholder` 用于触发器的无障碍标签 |
| `groupLabel` | `String` | `undefined` | 平铺选项列表上方的分组标题 |
| `placeholder` | `String` | `undefined` | 未选择时显示的提示文本 |
| `name` | `String` | `undefined` | 底层 `select` 的 `name` 属性，用于表单提交 |
| `form` | `String` | `undefined` | 底层 `select` 关联的表单 |
| `autoComplete` | `String` | `undefined` | 隐藏 `select` 的 `autocomplete` 属性，用于启用浏览器自动填充，例如省州字段用 `address-level1` |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | 触发器高度，可为 `sm`、`md` 或 `lg` |

### Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `autoComplete` | `string` |  | 隐藏 `select` 的 `autocomplete` 属性，用于启用浏览器自动填充，例如省州字段用 `address-level1` |
| `closeOnSelect` | `boolean` | `true` | 选中选项后是否关闭 select |
| `collection` | `ListCollection<T>` |  | 选项集合 |
| `composite` | `boolean` | `true` | select 是否与 tabs、combobox 等复合组件组合使用 |
| `defaultHighlightedValue` | `string` |  | select 打开时高亮项的初始值；不需要控制高亮值时使用 |
| `defaultOpen` | `boolean` |  | select 的打开状态是否受控 |
| `defaultValue` | `string[]` |  | select 渲染时的初始默认值；不需要控制 select 值时使用 |
| `deselectable` | `boolean` |  | 是否点击已选项清空值；仅单选模式适用 |
| `disabled` | `boolean` |  | select 是否禁用 |
| `form` | `string` |  | 底层 select 关联的表单 |
| `highlightedValue` | `string` |  | 高亮项的受控键值 |
| `id` | `string` |  | 组件内部状态机的唯一标识 |
| `ids` | `Partial<{ root: string; content: string; control: string; trigger: string; clearTrigger: string; label: string; hiddenSelect: string; positioner: string; item(id: string \| number): string; itemGroup(id: string \| number): string; itemGroupLabel(id: string \| number): string; }>` |  | select 各元素的 id，适合组合使用 |
| `invalid` | `boolean` |  | select 是否无效 |
| `loopFocus` | `boolean` | `false` | 键盘导航是否在选项间循环 |
| `modelValue` | `string[]` |  | select 的模型值 |
| `multiple` | `boolean` |  | 是否允许多选 |
| `name` | `string` |  | 底层 select 的 `name` 属性 |
| `open` | `boolean` |  | select 菜单是否打开 |
| `positioning` | `select.PositioningOptions` |  | 菜单的定位选项 |
| `readOnly` | `boolean` |  | select 是否只读 |
| `required` | `boolean` |  | select 是否必填 |
| `scrollToIndexFn` | `(details: select.ScrollToIndexDetails) => void` |  | 滚动到指定索引的函数 |
| `translations` | `select.IntlTranslations` |  | 无障碍元素及其状态的本地化文案 |
