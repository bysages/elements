## AiConversation

对话日志容器：所有消息都渲染在这一栏中，并作为屏幕阅读器的地标。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `autoScroll` | `Boolean` | `true` | 回复流式生长时，读者停在底边就跟随滚动；向上回读即停止拽动，回到底边自动恢复 |

## AiContent

气泡内容区，用来放置两侧通用的内容。

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

## AiActions

消息下方的操作区，通常包含复制、重试和反馈按钮。

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

## AiLoader

AI 处理中的对话轮次显示的加载提示。

纯造型的部件——自身没有属性，沿用部件结构的共享样式。

## Media

AI SDK 媒体：文件或推理文件片段。浏览器能播放的图像、音频、视频使用原生查看器，其他类型显示为带文件名的下载链接。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `part` | `Object as PropType<AiSdkMediaPart>` | `undefined` | AI SDK 的媒体片段；提供后忽略下面的直接属性 |
| `mediaType` | `String` | `undefined` | 未提供 `part` 时的 IANA 媒体类型 |
| `url` | `String` | `undefined` | 未提供 `part` 时的媒体地址 |
| `filename` | `String` | `undefined` | 文件下载链接显示的文件名和辅助名称 |
| `alt` | `String` | `undefined` | 图像的替代文本；默认使用文件名 |

## Parts

AI SDK 消息部件渲染器：按 `UIMessage.parts` 依次渲染文本、推理、工具、来源、媒体等类型；应用自有数据可通过同名插槽接管，工具审批事件保留给调用方。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `message` | `Object as PropType<AiSdkMessage>` | — | 要渲染的 AI SDK `UIMessage` |
| `highlighter` | `Function as PropType<(code: string, lang?: string) => string>` | `undefined` | 传给每个文本片段的代码高亮函数 |

| 事件 | 载荷 |
| --- | --- |
| `approve` | `(_event: { part: AiSdkToolPart; index: number }) => true` |
| `deny` | `(_event: { part: AiSdkToolPart; index: number }) => true` |
