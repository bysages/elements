## JsonTreeView

The one-tag path for a read-only tree: `data` and the initial depth
are all a quiet ledger needs; deeper control stays on the anatomy.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `data` | `null` |  | — |
| `defaultExpandedDepth` | `Number` | `1` | — |

## Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `data` | `object` |  | 树中展示的数据 |
| `defaultExpandedDepth` | `number` |  | 默认展开的层级 |
| `quotesOnKeys` | `boolean` |  | 键名是否显示引号 |

| `selectionChange` | `details: TreeView.SelectionChangeDetails<JsonNode<any>>` |
| `loadChildrenComplete` | `details: TreeView.LoadChildrenCompleteDetails<JsonNode<any>>` |
