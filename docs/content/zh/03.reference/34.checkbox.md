## Checkbox

The complete checkbox behind one checked model and its label.

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `modelValue` | `Boolean` | `undefined` | — |
| `defaultValue` | `Boolean` | `false` | — |
| `label` | `String` | `undefined` | — |
| `disabled` | `Boolean` | `false` | — |
| `invalid` | `Boolean` | `false` | — |
| `required` | `Boolean` | `false` | — |
| `readOnly` | `Boolean` | `false` | — |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | One rung for the control's box: the tick scales with it. |

| 事件 | 载荷 |
| --- | --- |
| `update:modelValue` | `value: Boolean` |

## Root

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `checked` | `checkbox.CheckedState` |  | 复选框的受控选中状态 |
| `defaultChecked` | `checkbox.CheckedState` |  | 复选框初始选中状态；无需控制选中状态时使用 |
| `disabled` | `boolean` |  | 复选框是否禁用 |
| `form` | `string` |  | 复选框所属表单的 id |
| `id` | `string` |  | 组件内部状态机的唯一标识 |
| `ids` | `Partial<{ root: string; hiddenInput: string; control: string; label: string; }>` |  | 复选框内各元素的 id；便于组合使用 |
| `invalid` | `boolean` |  | 复选框是否无效 |
| `name` | `string` |  | 复选框输入字段的名称，用于表单提交 |
| `readOnly` | `boolean` |  | 复选框是否只读 |
| `required` | `boolean` |  | 复选框是否必填 |
| `value` | `string` | `"on"` | 复选框 input 的值，用于表单提交 |

| 事件 | 载荷 |
| --- | --- |
| `checkedChange` | `details: CheckedChangeDetails` |
| `update:checked` | `checked: CheckedState` |

## Group

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `defaultValue` | `string[]` |  | 非受控时 `value` 的初始值 |
| `disabled` | `boolean` |  | 为 `true` 时禁用复选框组 |
| `invalid` | `boolean` |  | 为 `true` 时复选框组无效 |
| `maxSelectedValues` | `number` |  | 可选值的最大数量 |
| `modelValue` | `string[]` |  | 复选框组的受控值 |
| `name` | `string` |  | 复选框组内输入字段的名称，用于表单提交 |
| `readOnly` | `boolean` |  | 为 `true` 时复选框组只读 |

| 事件 | 载荷 |
| --- | --- |
| `valueChange` | `value: string[]` |
| `update:modelValue` | `value: string[]` |
