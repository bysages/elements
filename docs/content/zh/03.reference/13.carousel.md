Useful for composition.                                                                            |
| `inViewThreshold` | `number \| number[]`                                                                                                                                                             | `0.6`          | The threshold for determining if an item is in view.                                                                                        |

| `snapType`        | `'proximity' \| 'mandatory'`                                                                                                                                                     | `"mandatory"`  | The snap type of the item.                                                                                                                  |
