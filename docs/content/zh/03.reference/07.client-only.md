## ClientOnly

无属性。组件只有两个插槽：服务端渲染 `fallback`，客户端挂载后以
`default` 顶替。

| 插槽 | 说明 |
| --- | --- |
| `default` | 子内容，仅在客户端、水合之后渲染 |
| `fallback` | 服务端先行渲染的占位，驻留至挂载为止 |
