## User

A person on one line: the seal before the words, the name and its
quiet echo beneath. The mark is the Avatar itself — one component
renders it here, so every size and shape the Avatar knows the user
inherits; this row only lays the words out beside it.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` |  | The person's name — the loud line. |
| `description` | `String` | `undefined` | The quiet echo beneath the name: a role, a title, an address. |
| `size` | `String as PropType<AvatarSize>` | `undefined` | Seal diameter: one rung of the Avatar's own ladder. |
| `src` | `String` | `undefined` | — |
| `shape` | `String as PropType<"circle" \| "square">` | `"circle"` | — |
