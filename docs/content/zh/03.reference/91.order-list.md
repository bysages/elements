## OrderList

OrderList：可排序列表。行可以通过拖柄或侧边箭头移动，组把新顺序作为值上报，模型就是顺序。拖拽使用原生 drag 事件，primary 墨色发丝线标记行将落入的位置；触屏则通过按钮排序。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `modelValue` | `Array as PropType<string[]>` |  | 按当前顺序排列的行；值的顺序就是行的顺序 |
| `options` | `Array as PropType<OrderOption[]>` |  | 可显示的全部行，不保证顺序 |
| `label` | `String` | `undefined` | — |
