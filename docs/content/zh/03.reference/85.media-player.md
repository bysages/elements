## AudioRoot

音频解剖形态：Root 管理状态，Stage 和原生媒体承载来源，控制栏可自由组合。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `label` | `String` | `"Media player"` | 整个播放器的可访问名称 |
| `src` | `String` | `undefined` | 主媒体来源；需要编码回退时改用 `sources` |
| `sources` | `Array as PropType<MediaSourceOption[]>` | `() => []` | 多个媒体来源，用于浏览器选择可解码的编码 |
| `tracks` | `Array as PropType<MediaTextTrackOption[]>` | `() => []` | WebVTT 字幕或说明轨道 |
| `autoplay` | `Boolean` | `false` | 是否自动播放 |
| `loop` | `Boolean` | `false` | 是否循环播放 |
| `muted` | `Boolean` | `false` | 是否静音 |
| `preload` | `String as PropType<"none" \| "metadata" \| "auto">` | `"metadata"` | 预加载策略：`none`、`metadata` 或 `auto` |
| `volume` | `Number` | `1` | 默认音量 |
| `playbackRate` | `Number` | `1` | 默认播放速率 |
| `playbackRates` | `Array as PropType<number[]>` | `() => [0.5, 0.75, 1, 1.25, 1.5, 2]` | 可选播放速率列表 |
| `disabled` | `Boolean` | `false` | 是否禁用播放器控制 |
