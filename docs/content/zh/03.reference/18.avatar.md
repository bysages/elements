## Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `String as PropType<AvatarSize>` | `undefined` | Seal diameter: one rung of the control-height ladder. The default stands as tall as the biggest control, so an avatar rides a row without stretching it. |
| `shape` | `String as PropType<"circle" \| "square">` | `"circle"` | The corner: round by default; square cuts it sharp, a stamp beside a round portrait. |
| `id` | `string` |  | The unique identifier of the machine. |
| `ids` | `Partial<{ root: string; image: string; fallback: string; }>` |  | The ids of the elements in the avatar. Useful for composition. |
