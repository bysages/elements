## Install

:::code-group
```bash [Vue]
pnpm add @bysages/vue @bysages/core
```
```bash [React]
pnpm add @bysages/react @bysages/core
```
```bash [Solid]
pnpm add @bysages/solid @bysages/core
```
```bash [Svelte]
pnpm add @bysages/svelte @bysages/core
```
:::

The wrapper packages import `@bysages/core` themselves; you only need it directly for the theme engine.

## Apply the theme

Call `applyTheme` once on the client — it writes the theme attributes on the root element and persists them.

```ts
import { applyTheme, initTheme } from "@bysages/core";

// restore the persisted theme and follow the OS for mode: "system"
initTheme();

// or set a full theme explicitly
applyTheme({ mode: "dark", accent: "celadon", scene: "studio" });
```

## Use a component

```vue
<script setup lang="ts">
import { Button } from "@bysages/vue";
</script>

<template>
  <Button variant="solid" tone="ink">Publish</Button>
</template>
```

Each wrapper injects its own stylesheet (and the token layer) on first use — no CSS import to remember. For SSR, pass `tokensCss` from `@bysages/core` to a head tag so the first paint already carries the theme.
