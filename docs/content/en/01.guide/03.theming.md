title: Theming
description: Five theme dimensions, their values and defaults, and how to override tokens.
---

Elements resolves its visual system from five attributes on the root element. The theme engine in `@bysages/core` writes these attributes and persists changes; static pages can also write them directly.

| Attribute | Values | Default | Controls |
| --- | --- | --- | --- |
| `data-theme` | `light`, `dark`, `system` | `system` | Paper and lacquer color modes |
| `data-accent` | `auto`, `ink`, and the mineral pigments | `auto` | Primary actions and focus |
| `data-scene` | `auto` and the registered scenes | `auto` | Shape, spacing, motion, and light |
| `data-density` | `compact`, `default`, `comfortable`, `spacious` | `default` | Whitespace and control spacing |
| `data-contrast` | `auto`, `normal`, `high` | `auto` | Text, hairline, and focus strength |

```ts
import { applyTheme } from "@bysages/core";

applyTheme({
  mode: "dark",        // "light" | "dark" | "system"
  accent: "zhusha",    // "auto" | "ink" | "qinghua" | "celadon" | "zhusha" | "feicui" | "jilan" | "qingjin"
  scene: "civic",      // "auto" | "civic" | "enterprise" | "studio" | "tech" | "cupertino" | "expressive" | "fluent" | "material" | "sketch" | "missive" | "dispatch" | "metric" | "new-york" | "archive"
  density: "spacious", // "compact" | "default" | "comfortable" | "spacious"
  contrast: "high",    // "auto" | "normal" | "high"
});
```

`applyTheme` merges omitted dimensions with the active theme, writes the root attributes, and returns the resolved `Theme`. It stores the logical theme under the `bs-theme` key in `localStorage`; pass `persist: false` to change the current page without storing it. `initTheme` restores the stored theme and follows the operating system while `mode` is `system`; `getTheme` reads the active logical theme.

## Mode

`light` renders the paper mode. `dark` renders warm lacquer-black—not `#000`—while retaining the same hue relationships at brighter steps. `system` resolves through `prefers-color-scheme` when the theme is applied.

## Accent

`data-accent` colors primary action blocks and the focus halo. Success, warning, danger, and info remain semantic colors and never change with the accent.

| Value | Reads as | Note |
| --- | --- | --- |
| `ink` | Monochrome ink | Explicitly disables an accent pigment |
| `qinghua` | Cobalt blue | 青花 |
| `celadon` | Pale water green | 天水碧 |
| `zhusha` | Cinnabar red | Seal-paste red; the civic pairing |
| `feicui` | Jade green | 翡翠; the missive pairing |
| `jilan` | Azure blue | 霁蓝; the dispatch pairing |
| `qingjin` | Lapis blue | 青金; the metric pairing |
| `auto` | Scene pairing | Resolves with the active scene |

## Scene

`data-scene` retunes shape, density, motion, and the direction of light across the whole interface without forking components.

| Value | Name | Serves | Paired accent | Paired contrast |
| --- | --- | --- | --- | --- |
| `civic` | 典章 | Elder-facing and government desktops | `zhusha` | `high` |
| `enterprise` | 信笺 | Quiet commercial long sessions | `qinghua` | `normal` |
| `studio` | 雅集 | Design and editorial work | `celadon` | `normal` |
| `tech` | 司南 | Modern precision and throughput | `ink` | `normal` |
| `cupertino` | 圆融 | Soft, airy handheld interfaces | `qinghua` | `normal` |
| `expressive` | 飞白 | Playful, motion-first products | `zhusha` | `normal` |
| `fluent` | 流水 | Restrained productivity suites | `qinghua` | `normal` |
| `material` | 格物 | Layered, elevation-led surfaces | `celadon` | `normal` |
| `sketch` | 写意 | Hand-drawn character | `zhusha` | `normal` |
| `missive` | 家书 | Familiar handheld products | `feicui` | `normal` |
| `dispatch` | 公牍 | Office handheld products | `jilan` | `normal` |
| `metric` | 格律 | Metric enterprise products | `qingjin` | `normal` |
| `new-york` | 玄素 | Monochrome developer tools | `ink` | `normal` |
| `archive` | 档案 | Archive studio and editorial grids | `ink` | `normal` |

The audience scenes—civic, enterprise, studio, and tech—are Elements' own registers. The remaining scenes are named for a shared temperament rather than a product brand:

| Value | Tempered by |
| --- | --- |
| `cupertino` 圆融 | The iOS design language |
| `expressive` 飞白 | Spring-motion-led mobile design |
| `fluent` 流水 | Fluent's measured productivity register |
| `material` 格物 | Material's elevation-led layering |
| `missive` 家书 | Open mobile style specs such as WeUI |
| `dispatch` 公牍 | WeUI for Work |
| `metric` 格律 | TDesign's enterprise register |
| `sketch` 写意 | Hand-drawn sketchbooks and comics |
| `new-york` 玄素 | shadcn/ui's monochrome developer register |
| `archive` 档案 | Swiss International Style and studio archives |

A scene pairing applies only while the related dimension is `auto`. An explicit `accent` or `contrast` always wins—for example, `applyTheme({ scene: "civic", accent: "qinghua" })` keeps civic geometry and uses cobalt. `SCENE_DEFAULT_ACCENT` and `SCENE_DEFAULT_CONTRAST` export the pairing tables.

## Density and contrast

`data-density` changes whitespace—gaps, padding, and control spacing—not type size. `compact` tightens the layout, `default` is balanced, `comfortable` adds air, and `spacious` maximizes separation.

`data-contrast="high"` raises secondary text and hairlines toward primary strength and deepens the focus halo. `normal` is the baseline; `auto` follows the scene.

## Overriding tokens

Themes select token values; application CSS can replace them. Tokens live in `@layer bs.tokens`, so an unlayered rule wins without specificity tricks:

```css
:root {
  --bs-radius-sm: 4px;
  --bs-color-primary: var(--bs-color-ink);
}
```

Theme attributes cascade, so they can scope a subtree instead of `<html>`. A panel marked `data-scene="studio"` can therefore sit inside a civic page while the page keeps its own scene.
