## AiConversation

The log itself: the column every stroke lands in, a landmark to screen readers. While the reply streams, the log follows its growth — but only while the reader rests at the bottom edge. Climb up to reread a thought and the stream stops yanking the view back down; return to the bottom and the follow resumes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `autoScroll` | `Boolean` | `true` | Follow the stream's growth while the reader rests at the bottom. |

## Media

One SDK file or reasoning-file part. Browsers get the native viewer for media they can play; every other media type remains a download link with its filename.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `part` | `Object as PropType<AiSdkMediaPart>` | `undefined` | The AI SDK part. Supply this, or supply the direct props below. |
| `mediaType` | `String` | `undefined` | The part's IANA media type when no `part` is supplied. |
| `url` | `String` | `undefined` | The media source when no `part` is supplied. |
| `filename` | `String` | `undefined` | The accessible label and filename shown for a file download. |
| `alt` | `String` | `undefined` | Accessible text for an image; filename is the sensible default. |

## Parts

Renders one typed `UIMessage` from AI SDK as the shared conversation anatomy. SDK state stays authoritative: streaming reasoning opens, completed reasoning folds, approval state maps to tool actions, and unknown data parts wait for their application slot.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `message` | `Object as PropType<AiSdkMessage>` | — | The AI SDK message to render. |
| `highlighter` | `Function as PropType<(code: string, lang?: string) => string>` | `undefined` | Optional markdown highlighter passed to every text part. |
