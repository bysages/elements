## ClientOnly

No props. The component carries two slots: the server renders
`fallback`, the client replaces it with `default` once mounted.

| Slot | Description |
| --- | --- |
| `default` | The children, rendered on the client only — after hydration |
| `fallback` | What the server renders in the meantime, and what stays until mount |
