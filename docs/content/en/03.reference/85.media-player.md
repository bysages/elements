## AudioRoot

Audio and video share one instrument: the same state, the same keys,
and the same control rhythm, while each face keeps its native element's
own semantics. The parts — Root, Stage, Media, Controls, PlayButton,
Timeline, Time, MuteButton, Volume, Rate, Captions, PipButton,
FullscreenButton.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `String` | `"Media player"` | The accessible name for the whole player. |
| `src` | `String` | `undefined` | The primary source; use `sources` instead for codec fallbacks. |
| `sources` | `Array as PropType<MediaSourceOption[]>` | `() => []` | — |
| `tracks` | `Array as PropType<MediaTextTrackOption[]>` | `() => []` | — |
| `autoplay` | `Boolean` | `false` | — |

| `playbackRates` | `Array as PropType<number[]>` | `() => [0.5, 0.75, 1, 1.25, 1.5, 2]` | — |
| `disabled` | `Boolean` | `false` | — |
