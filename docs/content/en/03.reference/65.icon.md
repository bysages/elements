## Icon

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `String` | `"inherit"` | Size steps follow the surrounding font size; `inherit` is the default — one em of the text the icon sits in. |
| `label` | `String` | `undefined` | The accessible name. Without it the icon is presentation-only and hidden from the accessibility tree. |
