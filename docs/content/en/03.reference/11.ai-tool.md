## AiTool

A tool call: the shared collapsible as the vessel — the name it was reached by and the state it reached in on the trigger, its input and output folded inside.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` | — | The name the tool was reached by — shown raw on the trigger unless the `label` slot speaks friendlier words. |
| `status` | `String as PropType<"pending" \| "running" \| "completed" \| "error" \| "denied">` | — | The state the call reached — pending, running, completed, error, or denied; stamped on the fold and whispered in the status chip. |
| `approval` | `String as PropType<"required" \| "approved" \| "denied">` | — | The human approval gate, when the call needs one. |
| `inputValue` | `[String, Number, Boolean, Object, Array] as PropType<ToolValue>` | `undefined` | The machine-readable request, formatted when no `input` slot is given. |
| `outputValue` | `[String, Number, Boolean, Object, Array] as PropType<ToolValue>` | `undefined` | The machine-readable answer, formatted when no `output` slot is given. |
| `defaultOpen` | `Boolean` | `false` | The fold arrives open when set — rides the shared collapsible. |

| Event | Payload |
| --- | --- |
| `approve` | `() => true` |
| `deny` | `() => true` |

| Slot |
| --- |
| `#input` |
| `#label` |
| `#output` |
