## AutoComplete

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `modelValue` | `String` | `""` | — |
| `items` | `Array as PropType<string[]>` | `() => []` | — |
| `placeholder` | `String` | `undefined` | — |
| `filter` | `Function as PropType<(item: string, input: string) => boolean>` | `undefined` | Field text to match against; defaults to the item itself. |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | One rung of the control-height ladder for the field row. |
| `portal` | `[Boolean, String] as PropType<FloatingPortalTarget>` | `false` | After hydration, render the floating vessel in `body` (`true`) or a selector; `false` keeps it inline. |

| Event | Payload |
| --- | --- |
| `update:modelValue` | `(_value: string) => true` |
