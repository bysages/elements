### Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `count` | `number` |  | The total number of steps |
| `defaultStep` | `number` |  | The initial value of the stepper when rendered. Use when you don't need to control the value of the stepper. |
| `id` | `string` |  | The unique identifier of the machine. |
| `ids` | `steps.ElementIds` |  | The custom ids for the stepper elements |
| `isStepSkippable` | `(index: number) => boolean` |  | Function that returns whether a step can be skipped |
| `isStepValid` | `(index: number) => boolean` |  | Function that returns whether a step is valid |
| `linear` | `boolean` |  | If `true`, the stepper requires the user to complete the steps in order |
| `orientation` | `'horizontal' \| 'vertical'` | `"horizontal"` | The orientation of the stepper |
| `step` | `number` |  | The controlled value of the stepper |
