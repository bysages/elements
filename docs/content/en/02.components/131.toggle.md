## Props

### Toggle

The complete pressed seal behind one label: the default content
swaps through the indicator, so one child serves both states.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `String` | `undefined` | The accessible name when the content is only a glyph. |

### Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultPressed` | `boolean` |  | The default pressed state of the toggle. |
| `disabled` | `boolean` |  | Whether the toggle is disabled. |
| `pressed` | `boolean` |  | The pressed state of the toggle. |

### Indicator

A styled part — no props of its own; it takes the anatomy's shared styling.
