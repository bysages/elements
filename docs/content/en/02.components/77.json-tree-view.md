## Props

### JsonTreeView

The one-tag path for a read-only tree: `data` and the initial depth
are all a quiet ledger needs; deeper control stays on the anatomy.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `null` |  | — |
| `defaultExpandedDepth` | `Number` | `1` | — |

### Root

| Prop | Type | Default | Description |

| `defaultExpandedDepth` | `number` |  | The default expand level. |
| `quotesOnKeys` | `boolean` |  | Whether to show quotes on the keys. |
