## Props

### AiConversation

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `autoScroll` | `Boolean` | `true` | Follow the stream's growth while the reader rests at the bottom. |

### AiJumpToLatest

The optional jump-to-latest door: an explicit part the caller drops inside the conversation when the log scrolls. It watches the log's distance from the bottom edge and surfaces only while the reader is away — clicking returns to the stream. Nothing renders by default.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `threshold` | `Number` | `96` | Bottom-edge distance beyond which the door surfaces. |

### AiContent

The bubble's inner measure — content that belongs to neither side specifically.

A styled part — no props of its own; it takes the anatomy's shared styling.

### AiActions

The quiet row under a message — copy, retry, feedback.

A styled part — no props of its own; it takes the anatomy's shared styling.

### AiLoader

The while-it-works whisper for the in-flight turns.

A styled part — no props of its own; it takes the anatomy's shared styling.

### Media

One SDK file or reasoning-file part. Browsers get the native viewer for media they can play; every other media type remains a download link with its filename.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `part` | `Object as PropType<AiSdkMediaPart>` | `undefined` | The AI SDK part. Supply this, or supply the direct props below. |
| `mediaType` | `String` | `undefined` | The part's IANA media type when no `part` is supplied. |
| `url` | `String` | `undefined` | The media source when no `part` is supplied. |
| `filename` | `String` | `undefined` | The accessible label and filename shown for a file download. |
| `alt` | `String` | `undefined` | Accessible text for an image; filename is the sensible default. |

### Parts

Renders one typed `UIMessage` from AI SDK as the shared conversation anatomy. SDK state stays authoritative: streaming reasoning opens, completed reasoning folds, approval state maps to tool actions, and unknown data parts wait for their application slot. The generic `MESSAGE extends AiSdkMessage` narrows every part and slot to the application's own `UIMessage` type.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `message` | `Object as PropType<AiSdkMessage>` | — | The AI SDK message to render. |
| `highlighter` | `Function as PropType<(code: string, lang?: string) => string>` | `undefined` | Optional markdown highlighter passed to every text part. |
