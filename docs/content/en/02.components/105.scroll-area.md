## Props

### ScrollArea

The complete scroll vessel around caller content, with one or both quiet
lanes depending on orientation.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `String as PropType<"vertical" \| "horizontal" \| "both">` | `"vertical"` | — |

### Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` |  | The unique identifier of the machine. |
| `ids` | `Partial<{ root: string; viewport: string; content: string; scrollbar: string; thumb: string; }>` |  | The ids of the scroll area elements |
