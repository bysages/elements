## Props

### TreeSelect

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `modelValue` | `String` | `undefined` | — |
| `data` | `Array as PropType<TreeSelectNode[]>` | — | — |
| `placeholder` | `String` | `"Select…"` | — |
| `filterable` | `Boolean` | `false` | — |
| `disabled` | `Boolean` | `false` | — |
| `invalid` | `Boolean` | `false` | — |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `"md"` | One rung of the ladder: the trigger height and the vessel's row register follow it together. |
| `portal` | `[Boolean, String] as PropType<FloatingPortalTarget>` | `false` | After hydration, render the floating vessel in `body` (`true`) or a selector; `false` keeps it inline. |
