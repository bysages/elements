## Props

### AvatarGroup

Avatars overlapping one row, each rimmed in the ground so the pile
stays legible.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `String as PropType<"sm" \| "md" \| "lg">` | `undefined` | One register for every seal: falls onto data-size for the stylesheet to re-point the avatars' measure. |
