## Props

### Root

| Prop       | Type                           | Default | Description                                 |
| ---------- | ------------------------------ | ------- | ------------------------------------------- |
| `disabled` | `boolean \| 'true' \| 'false'` |         | Indicates whether the fieldset is disabled. |
| `id`       | `string`                       |         | The id of the fieldset.                     |
| `invalid`  | `boolean`                      |         | Indicates whether the fieldset is invalid.  |
