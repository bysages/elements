## Props

### Tag

A small named seal for filtering and cataloguing. The resting shape is a span; `checkable` raises it to a pressed button, and `closable` hangs the removal seal inside — dismissal stays the consumer's state, the way the banner's does.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tone` | `String as PropType<"ink" \| "primary" \| "success" \| "warning" \| "danger" \| "info">` | `"ink"` | The pigment the tag is inked with; ink is the solemn default, and the fixed pigments speak for their meaning. |
| `variant` | `String as PropType<"solid" \| "outline" \| "subtle">` | `"solid"` | How the tag rests: a solid fill, an outline shell, a subtle wash. The pressed state always reads as solid. |
| `checkable` | `Boolean` | `false` | Render the tag as a pressed button the consumer can toggle. |
| `modelValue` | `Boolean` | `undefined` | The pressed state held from outside; omit it and the tag keeps its own state from `defaultValue`. |
| `defaultValue` | `Boolean` | `false` | — |
| `closable` | `Boolean` | `false` | Render the quiet removal seal. |
| `disabled` | `Boolean` | `false` | — |
